# sushanthp.com

## Quick Setup

### 1. Add your Supabase keys to .env.local
Replace the placeholder values:
- NEXT_PUBLIC_SUPABASE_URL → your Supabase project URL
- NEXT_PUBLIC_SUPABASE_ANON_KEY → your Supabase anon key
(Get these from Supabase Dashboard → Settings → API)

### 2. Run the SQL in Supabase
Copy the contents of supabase-setup.sql and run it in your Supabase SQL Editor.

### 3. Your photo is already included
Located at public/photos/sushanth.png

### 4. Install and run
npm install
npm run dev

### 5. Admin panel
Go to /admin/login — password is in .env.local

### 6. Deploy to Vercel
Push to GitHub → connect to Vercel → add env vars → deploy
Then add sushanthp.com in Vercel → Settings → Domains
